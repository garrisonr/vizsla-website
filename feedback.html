An invitation

Tell us what would make it better

This is truly a labor of love, and constructive feedback is not a suggestion box here; it is the development process. Vizsla got built the way it will keep getting better: out loud, on the record, one decision at a time. If something is clumsy, say so. If something is missing, name it.

The honest state of the inbox

There is no form on this page, and there won’t be one until there is a real inbox behind it. A feedback form that mails into the void would be exactly the kind of fake this project exists to refuse — so here is what actually exists today:

  • If you run Vizsla: feedback rides the channel the system itself uses for every human decision — Pass or Paws, the decision inbox built into the OS. That is where the project’s questions already collect, and where answers already change what gets built next.
  • If you’re reading from the web: the public contact path — an address on the project’s own domain — opens when the site goes public. That decision (domain, host, and the address itself) belongs to Richard, and it is parked, on the record, rather than improvised here.

When that path opens, this page will say so, plainly, and the form that replaces this note will deliver to a person who reads every word — because so far, every word of feedback has.

What good feedback looks like here

  • “This screen made me stop and think” — thinking should be reserved for your work, not your tools.
  • “I looked for X in the obvious place and it wasn’t there.”
  • “My parent / my kid / my coworker would never find this.”
  • “It did something I didn’t ask it to do.” — the gravest charge in this house, and the fastest to get fixed.
